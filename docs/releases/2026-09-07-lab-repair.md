# Labs and 3D recovery — 7 September 2026

This repair targets the outer SashaInfinity / SILeos LMS checkout. It corrects
portability and course-backup gaps discovered while investigating missing labs,
3D models and the DNA scene in an imported copy.

## Findings and changes

- The previous source ZIP contained the 59 supplied lab pages and DNA code, but
  excluded runtime GLB uploads. Four complete registered models now ship in a
  checksummed library, with an administrator restore button and CLI. The private
  complete ZIP also preserves all 39 local GLB files and 13 course-content backups.
- The GLB viewer fetched blob URLs that the existing production CSP blocked.
  It now parses authenticated bytes and embedded texture data directly. The
  three deployment policies are unchanged. Offline lab players use the same path.
- Model paths written on Windows now resolve on Linux, missing optional model
  tiers fall back to the original, and both production Compose variants persist
  model storage. `THREE_D_ROOT` supports custom persistent storage.
- The supplied lab pages linked back to a missing index. The build now generates
  that index and validates its links. `scripts/preview_labs.py` provides a simple
  local HTTP preview independent of the LMS database.
- Four historical lab slugs resolve to the corresponding supplied simulations.
  Retired PhET/default simulations remain absent from the active catalog.
- Course backups now include quiz 3D tasks and their model/lab dependencies,
  remapping IDs during restore. Historical graded labs that become ungraded
  supplied simulations are restored as draft lesson investigations with an
  explicit grading-review warning.
- Migration 0028 now tolerates tables already created at startup and an empty
  core schema, fixing failures in fresh import and upgrade workflows.
