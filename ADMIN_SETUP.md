## Admin Seeding Script

### Running the Script Manually

```bash
# Enter the backend directory
cd /www/wwwroot/sasha_lms/backend

# Run the admin seeding script
docker-compose exec backend python seed_admin_simple.py
```

### Customizing Admin Credentials

You can customize the admin credentials by setting environment variables in your `.env` file:

```bash
# Admin Account Configuration
ADMIN_EMAIL=your-admin-email@domain.com
ADMIN_USERNAME=your-admin-username
ADMIN_PASSWORD=YourSecurePassword123!
ADMIN_FIRST_NAME=YourFirstName
ADMIN_LAST_NAME=YourLastName
```

## Troubleshooting

### Common Issues

1. **Database Connection Error**
   ```bash
   # Check if database is running
   docker-compose ps

   # Restart services if needed
   docker-compose restart postgres
   ```

2. **Permission Errors**
   ```bash
   # Ensure script is executable
   chmod +x seed_admin_simple.py
   ```

3. **Admin Already Exists**
   - The script will update existing admin accounts
   - No duplicate accounts will be created

### Reset Admin Password

To reset the admin password, update the environment variable and re-run the script:

```bash
# Update password in .env

docker-compose exec backend python seed_admin_simple.py
```
